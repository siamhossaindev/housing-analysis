# Housing Data Cleaning & Exploration

## Overview
Cleaning and exploratory analysis of a housing dataset from Kaggle,
using Python and pandas.

## Dataset
- Source: [Housing.csv](https://www.kaggle.com/datasets/hosammhmdali/house-price-dataset) on Kaggle
- Author: (Hosam Mhmd Ali)
- License: (Apache 2.0)

## What I did
1. Checked for and removed duplicate rows
2. Checked for missing values (none found)
3. Investigated outliers using people per household
4. Saved the cleaned data

## Key findings
- Population and households show a strong positive relationship
- A few areas have unusually high or low people-per-household values

## How to run
pip install pandas matplotlib jupyter
jupyter notebook housing_analysis.ipynb
